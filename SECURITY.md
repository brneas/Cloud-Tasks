# Security policy

## Supported releases

Security fixes are provided for the latest Cloud Tasks release. Older releases
may be asked to upgrade before a report is investigated.

## Report a vulnerability privately

Use **Report a vulnerability** on the repository's GitHub Security page. This
opens a private security advisory visible only to the reporter and project
maintainers.

If private vulnerability reporting is temporarily unavailable, open a public
issue requesting a private contact channel. Do not include vulnerability
details in that issue.

Never submit a real Nextcloud URL, username, app password, signing key, task
document, database, or exported calendar. Use a minimal reproduction with
redacted fixtures and include the affected Cloud Tasks, Flutter, Android, and
Nextcloud versions.

The maintainer will acknowledge the report and coordinate public disclosure and
credit after a fix is available. Please do not publish an unresolved
vulnerability first.

For the application's security and data-flow design, see
[docs/security.md](docs/security.md).
